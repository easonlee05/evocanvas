# Object Prompt（对象提示）

## 1. 定位

对象提示负责把自由生成压缩为 EvoCanvas 可治理的结构化对象。

它的重点不是让结果更像自然语言答案，而是让结果更像可继续推进的工作对象。

## 2. 主要职责

对象提示至少应约束以下事项：

- 当前产出属于哪类对象
- 该对象的最小语义边界是什么
- 哪些内容必须显式出现
- 哪些内容不得越级声明成立

## 3. 当前优先对象

EvoCanvas 1.0 当前优先支持的对象包括：

- 来源片段（source fragment）
- 解释对象（interpretation）
- 待澄清项（clarification）
- 约束（constraint）
- 待决策候选（decision candidate）
- 结构化交接物（structured handoff）

## 4. 当前边界

对象提示不负责判断：

- 这个对象现在该不该生成
- 这个对象是否已经过验证
- 这个对象是否已经获准生效

它只负责在被允许生成时，把对象语义做对。
