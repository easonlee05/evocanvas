# 618 积分商城误杀治理：技术约束

## 已确认约束

1. 结算中心本期禁止改动。
2. 现有风控链路不接受大规模重构。
3. 一期只能优先新增轻量规则能力。
4. 新增拦截逻辑对主链路额外耗时 P95 不能超过 120ms。
5. 必须保留人工审核与事后追溯能力。

## 当前实现边界

1. 当前服务链路更适合在现有风控节点上追加规则判断。
2. 不适合在一期直接建设复杂模型训练和在线推理闭环。
3. 不适合在一期同时改造结算、申诉、客服后台三套系统。

## 技术风险提示

1. 如果拦截粒度设计不当，误杀可能继续扩大。
2. 如果没有人工放行兜底，客服侧压力会继续上升。
3. 如果性能约束被突破，主链路会受到影响。
