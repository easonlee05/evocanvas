# EvoCanvas 1.0 模块阅读索引

## 定位

本目录用于把 EvoCanvas 1.0 主 PRD 按模块拆成更易阅读的协作文档。

注意：

1. `docs/vision/EvoCanvas1.0-PRD.md` 仍然是唯一产品真相源。
2. 本目录文件用于阅读、评审和协作，不替代主 PRD。
3. 如果模块文档与主 PRD 存在冲突，以主 PRD 为准，并应在同一轮修订中同步更新。

1. 主 PRD：确认版本边界、范围和验收口径。

3. 挂件模块：理解辅助视图层与个人工具层。
