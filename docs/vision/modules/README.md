# EvoCanvas 1.0 模块 PRD 索引

## 定位

本目录用于把 EvoCanvas 1.0 主 PRD 按业务职责拆成可独立阅读、设计、实现和验收的模块 PRD。

注意：

1. `docs/vision/EvoCanvas1.0-PRD.md` 仍然是唯一产品真相源。
2. 本目录文件是主 PRD 纳入引用的规范性展开，承载模块字段、交互、状态机、异常和模块验收，不形成平行真相源。
3. 如果模块文档与主 PRD 存在冲突，以主 PRD 为准，并应在同一轮修订中同步更新。
4. 同一详细规则只在一个模块 PRD 中维护；跨模块共同门禁统一由主 PRD 定义。

## 当前模块

1. [input-and-dialogue.md](./input-and-dialogue.md)
   输入与对话塑形模块 PRD，聚焦感觉接入、输入编译、右侧 AI 助手、Chat 确认与结构变化提议。
2. [canvas.md](./canvas.md)
   主画布模块 PRD，聚焦栏目、显影、布局、局部关系和画布投影。
3. [cards.md](./cards.md)
   卡片模块 PRD，聚焦业务对象与包版本的卡片投影、卡片类型、关系和迁移规则。
4. [widgets.md](./widgets.md)
   挂件模块 PRD，聚焦系统挂件、个人挂件预留以及项目时间轴和活跃缺口的边界。
5. [knowledge-base.md](./knowledge-base.md)
   项目知识库模块 PRD，聚焦原始来源、LLM Wiki 编译页、检索复用、工作区发布和事实边界。
6. [handoff.md](./handoff.md)
   结构化交接模块 PRD，聚焦交接内容、版本、确认、过时、AI PRD 派生和知识发布。

## 建议阅读顺序

1. 主 PRD：确认版本边界、范围和验收口径。
2. 输入与对话塑形：理解来源、候选、确认和稳定提交边界。
3. 主画布与卡片：理解稳定对象如何被显影和操作。
4. 挂件：理解辅助视图层与个人工具层。
5. 结构化交接：理解稳定上下文如何确认、过时和交给下游。
6. 项目知识库：理解可复用知识如何带着来源进入或离开工作区。
