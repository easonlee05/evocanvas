# Memory（记忆）

> 当前成熟度层级：`L2 对象与流程定义层`
> 编码门槛：`未达到 L3，不应直接作为稳定实现规格；需继续补齐对象存储、复水和过时策略`

## 1. 这一层回答什么问题

记忆文档回答：

- 系统长期保存什么。
- 什么只作为当前工作面临时存在。
- 旧输入、旧卡片、旧交接物什么时候还能被复用。
- 哪些历史只能作为追溯材料，不能重新成为当前事实。

EvoCanvas 的记忆不是“对话历史管理”，而是“结构化产品思考记忆管理”。

## 2. 记忆和上下文的区别

上下文回答“本轮模型应该看到什么”，记忆回答“系统长期沉淀了什么”。

因此：

- 长聊天记录不是主要事实层。
- 原始材料不是默认每轮都进入模型。
- 卡片、关系、约束、待决策、交接物和快照是主要工作记忆。
- 记忆被带入当前轮时，必须经过上下文装配，而不是全文回放。

## 3. 记忆设计原则

### 3.1 保留来源，不伪造确定性

原始输入、截图说明、聊天摘录、会议片段和用户裁决都应保留来源线索。

系统可以提炼，但不能让提炼结果切断来源。

### 3.2 记住未知，而不只记住结论

EvoCanvas 要长期记住：

- 还有哪些问题没清楚
- 哪些对象存在冲突
- 哪些判断尚未确认
- 哪些内容已经过时但仍有追溯价值

### 3.3 稳定事实优先，但不抹掉历史

已确认约束、已完成决策和已确认交接物应优先保存为稳定记忆。

但被替代的约束、被关闭的待澄清和过时交接物不能直接删除；它们需要保留为冷历史，服务回看、冲突追溯和过时判断。

### 3.4 复用按对象依赖，不按时间回放

当需要复用历史时，应根据当前卡片、关系、来源和状态链复水，而不是按时间顺序回放全部聊天。

## 4. 四层记忆模型

### 4.1 原始材料层

保存输入原文与外部引用。

包括：

- 用户一句感觉或临时想法
- 会议纪要
- 聊天摘录
- 截图说明
- 反馈、竞品资料和文档片段
- 用户裁决或确认记录

作用：

- 作为可追溯基础。
- 在需要证据细节时复水。
- 支撑“已确认”和“已生效”判断。

### 4.2 工作对象层

保存当前主题推进所需的主要结构化对象。

包括：

- 证据卡
- 问题卡
- 待澄清卡
- 约束卡
- 待决策 / 方案承接卡
- 交接物承接卡
- 卡片关系

这是当前画布和右侧 AI 助手最常使用的记忆层。

### 4.3 稳定结论层

保存已满足条件的稳定对象。

包括：

- 已生效约束
- 已完成决策
- 已确认边界
- 已确认交接物

特点：

- 数量少
- 权重高
- 必须有来源、确认方式或用户裁决
- 可以成为后续推理前提

### 4.4 冷历史层

保存旧快照、被替代对象、过时交接物、已关闭问题和旧版本解释。

特点：

- 默认不进入当前上下文
- 仅在诊断、回看、复盘或冲突追溯时复水

## 5. 记忆和工作台对象的关系

### 5.1 卡片

卡片是工作对象层的主要显影方式。

卡片内容可以被编辑、移动、确认、关闭或替代，但其事实地位仍由来源、状态和确认记录决定。

### 5.2 系统挂件

Active Todos 和项目时间轴是系统挂件。

它们只投影当前状态，不成为独立记忆事实。

例如：

- Active Todos 来源于待澄清卡、待决策 / 方案承接卡和少量待确认约束卡。
- Todo 完成后应同步回写源卡状态。
- Todo 本身不作为独立事实保留。

### 5.3 个人挂件

个人挂件服务个人思考和操作便利。

1.0 中，个人挂件默认不进入正式对象链路，不参与结构化交接物，也不应被 AI 直接视为已确认事实。

## 6. 复水策略

需要补充历史时，按以下顺序复水：

1. 当前对象直接引用的来源。
2. 当前对象的上游证据。
3. 与当前冲突相关的相对证据。
4. 当前对象最近一次状态变化记录。
5. 相关交接物摘要。
6. 必要的历史回合回执。

不建议直接按时间顺序全文回放。

## 7. 交接物与快照

### 7.1 交接物

结构化交接物不是导出文档，而是面向下一位人或下一轮 AI 的上下文切换包。

它需要保留：

- 当前目标
- 输入背景
- 已确认约束
- 已完成决策
- 仍未解决的问题
- 待确认决策
- 推荐后续动作

### 7.2 快照

快照不是画布截图，也不是简单备份。

它是某个时点的收敛状态冻结点，用于：

- 回看当时哪些内容已确认。
- 判断某个交接物是否已过时。
- 追溯某个约束或决策为什么成立。

## 8. 设计禁令

- 不允许把聊天历史当作主要事实层。
- 不允许把所有原始材料全文默认塞进模型上下文。
- 不允许删除未解决问题、冲突和过时对象的追溯线索。
- 不允许把系统挂件内容当作独立事实源。
- 不允许交接物只保留已确认内容而抹掉未决部分。

## 9. 1.0 最小落地要求

EvoCanvas 1.0 的记忆至少应具备：

- 原始材料、工作对象、稳定结论、冷历史四层记忆分工。
- 未解决待澄清项、冲突和待决策的显式记忆表示。
- 系统挂件不得成为独立事实源。
- 结构化交接物作为上下文切换包。
- 快照作为收敛状态冻结点，而不是只做备份。
