# Stage Prompt（阶段提示）

## 1. 定位

阶段提示是 EvoCanvas `prompt engineering` 的运行主控面之一。

它负责把当前回合明确绑定到具体阶段，而不是让模型总是用同一种思路回答。

## 2. 主要职责

阶段提示至少应回答四个问题：

- 当前处于哪个阶段
- 当前阶段允许做哪些动作
- 当前阶段不允许越级做哪些动作
- 当前阶段的最小输出应落到哪些对象

## 3. 当前默认阶段

阶段提示应服务以下五段主链：

1. 输入接入
2. 输入编译
3. 待澄清显影
4. 约束 / 决策收敛
5. 结构化交接

## 4. 设计要求

- 阶段提示不得覆盖系统基座提示
- 阶段提示不得自行改写治理门槛
- 阶段提示应避免把多个阶段目标混成同一次输出
- 阶段提示应优先限制越级生成，而不是鼓励多产出

## 5. 当前边界

阶段提示负责“当前应怎么推进”，但不负责：

- 决定结果是否验证通过
- 决定结果是否最终放行

这两项仍分别由验证与治理承担。
