# 618 积分商城误杀治理：问题背景

## 背景概述

618 活动期间，积分商城出现了明显的高误杀投诉。

当前管理层要求：

1. 一期先把误杀率压下来。
2. 活动窗口内必须给出可执行方案。
3. 不能为了快速上线而破坏结算中心现有链路。

## 当前现象

1. 一部分正常用户在积分兑换时被风控拦截。
2. 客服侧已经收到多起“明明是正常兑换却被拦截”的投诉。
3. 申诉入口和恢复路径不清晰，用户体验较差。
4. 运营担心活动期间误杀扩大后影响转化和 GMV。

## 当前目标

本轮不是直接设计完整长期方案，而是验证一期最小闭环是否能成立：

1. 先把问题收敛清楚。
2. 先识别关键待澄清项。
3. 再沉淀稳定约束。
4. 再形成需要拍板的待决策项。
5. 最后输出结构化交接物。
