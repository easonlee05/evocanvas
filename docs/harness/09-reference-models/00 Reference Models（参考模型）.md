# Reference Models（参考模型）

> 当前成熟度层级：`L1 参考框架层`

## 1. 文档目的

本组保存 EvoCanvas harness 参考过的外部模型和分类框架。

这些模型用于：

- 辅助归因。
- 对齐外部论文和行业语境。
- 帮助检查当前主骨架是否遗漏重要控制能力。

但它们不直接替代 EvoCanvas 的项目内设计规格。

其中 `original-harness-before-refactor/` 是从 `backup/backend-docs-before-refactor-20260701` 分支拉回的重构前原始文档归档，用于对照和迁移，不作为当前主骨架。

## 3. 使用原则

- 外部模型可以帮助发现盲区。
- 外部模型不能越过 EvoCanvas 1.0 产品边界。
- 外部模型中的术语若过于抽象，应在项目内翻译为可落地职责。
