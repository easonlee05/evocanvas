# Evaluation Metrics（评估指标）

> 当前成熟度层级：`L2 对象与流程定义层`

## 1. 这一层回答什么问题

评估指标回答：我们用什么信号判断 EvoCanvas 1.0 真的在降低需求失真，而不是只是在生成更多结构化内容。

指标必须服务 PRD 中的成功标准和验证命题，而不是服务表面热闹。

## 2. 核心命题指标

### 2.1 感觉接住率

衡量系统是否能先理解、命名和追问用户的 vibe，而不是在输入模糊时直接给结论。

关注点：

- 模糊输入后，系统是否先复述理解或提出具体追问。
- 用户是否认可“系统接住了我想表达的东西”。

### 2.2 关键缺口显影率

衡量真正影响推进的缺口，是否被显性化为待澄清卡或 Active Todos 投影。

关注点不是数量越多越好，而是关键缺口是否被及时看见。

### 2.3 冲突披露率

衡量系统是否能把来源冲突、约束冲突或判断冲突显性化，而不是静默合并。

关键问题：

- 冲突是否被用户看见。
- 是否能追溯来源。
- 是否避免在未裁决前继续按已生效使用。

### 2.4 约束确认可靠度

衡量进入已生效的约束，是否都有来源、确认方式或用户裁决记录。

关键问题：下游是否能稳定依赖这些约束，而不是一用就返工。

### 2.5 待决策清晰度

衡量系统是否能把“还没问清楚”和“必须拍板”区分开。

关键问题：

- 待决策项是否真的回指相关待澄清、约束或冲突。
- 用户是否知道为什么这里需要拍板，而不是继续追问。

### 2.6 交接物可继续率

衡量结构化交接物是否真的支持后续继续推进。

至少关注它是否明确包含：

- 当前目标
- 输入背景
- 已确认约束
- 已完成决策
- 未解决问题
- 待确认决策
- 推荐后续动作
- 关键来源

### 2.7 下游误解减少幅度

衡量使用结构化交接物或面向 AI 的 PRD 后，需求漏点、边界误读和返工是否少于直接交付聊天记录。

这是 1.0 最核心的长期价值指标之一。

## 3. 工作面健康指标

以下指标主要用于判断 harness 是否稳定，不直接代表产品命题已经成立：

- 高影响信息地位升级的确认依据覆盖率。
- 轻确认取消后的重复建议率。
- 交接物过时触发率。
- Active Todos 回源成功率。
- 里程碑提示与对象状态的一致性。
- 来源缺失提示率。
- 验证失败后的正确分流率。
- 回流后重新收敛成功率。

## 4. 对比评估建议

如果要判断 1.0 是否真的成立，最好做有对照的评估，而不是只看单边数据。

典型对比方式包括：

- 直接把聊天记录交给下游 vs 先经 EvoCanvas 收敛后再交付。
- 没有 Active Todos / 冲突显性化时的继续推进成本 vs 有这些能力后的继续推进成本。
- 用户自己手工整理上下文 vs 系统帮助完成结构收敛后的交接质量。

## 5. 不推荐作为主指标

以下指标可以辅助观察，但不应作为 1.0 主成功标准：

- 生成字数
- 单次回复满意度
- 卡片数量
- 对话轮数越少越好
- 交接物看起来像不像一份完整 PRD
- 用户是否觉得“AI 很聪明”

EvoCanvas 1.0 要证明的不是“更快产出一份文档”，而是“更可靠地收敛判断，并让下游更容易继续推进”。
