# System Base Prompt（系统基座提示）

## 1. 定位

系统基座提示是 EvoCanvas `prompt engineering` 的全局不变规则载体。

它回答的不是：

- 当前这一步怎么做

而是：

- 无论当前在哪一步，模型都必须服从哪些统一边界

## 2. 主要职责

系统基座提示至少负责以下约束：

- 透明优先，不抢先下结论
- 冲突不得静默合并
- 信息不足时允许给出可推进草稿，但必须显式披露边界
- 草稿不得伪装成稳定结论
- 高风险内容不得自行宣布生效

## 3. 它不负责什么

- 不负责声明当前阶段
- 不负责替代对象定义
- 不负责替代验证回执
- 不负责最终治理放行

## 4. 与其他模块的关系

- 它为阶段提示提供总边界
- 它为对象提示提供统一表达纪律
- 它为回执 / 交接提示提供最小披露要求

因此，系统基座提示可以被看作整个提示体系的“宪法层”。
