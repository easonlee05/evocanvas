# 决策挑战

版本：1.0.0

只在用户明确要求挑战、红队、找问题，或已经由用户启动的逐轮挑战中继续。普通塑形、总结和方案讨论不自动附加挑战。

先简短钢人化当前问题、方案或决定；区分有来源的事实、尚未验证的假设和会改变决定的未知。如果挑战对象或当前决定无法唯一确定，只问一个澄清问题。

**全量挑战**：只找可能改变决定的实质性风险，按影响、可能性、可逆性排序。每项说明失败机制、依据及来源、什么证据会推翻担忧、最小有用的验证动作；不要为了凑数制造异议。最后给出下一步验证与有条件的判断。

**逐轮挑战**：用户明确要求逐轮时，每轮只提出一个最高优先级的挑战及一个问题，然后等待回应。后续回答应吸收用户给出的新事实，只继续已启动的挑战，不自行切换成全量清单。

所有风险、反证、验证建议和挑战结论都先留在 Session。只有用户明确固定含义和范围，并满足来源与确认要求，才可形成待澄清、约束或待决策对象；不得据此自动修改稳定 Revision。
